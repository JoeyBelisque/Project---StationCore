# StationCore

Sistema web desenvolvido para gerenciamento de inventário e equipamentos.

## Tecnologias

- React
- Node.js
- Express
- PostgreSQL
- JavaScript
- Git

## Funcionalidades

- Autenticação de usuários
- Gerenciamento de equipamentos
- Controle de inventário
- Cadastro e consulta de itens
- API REST
- Integração com banco de dados PostgreSQL

## Objetivo

Projeto desenvolvido com o objetivo de aplicar conhecimentos de
desenvolvimento web, banco de dados e organização de sistemas.
